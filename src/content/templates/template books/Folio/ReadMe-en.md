# About the Folio Template {i18n="folio.template.title"}

A folio puts several books from this collection together, so you can print them as one book. {i18n="folio.template.what"}

# How to make a folio {i18n="folio.template.how"}

1. Make a new book from this template. {i18n="folio.template.how.new"}
2. Go to the Table of Contents page. Beside the list, click **Choose Books…** and pick the books you want, in the order you want them. {i18n="folio.template.how.choose"}
3. To choose how the books are joined, click **Settings…** beside the list. You can also find these in **Book and Page Settings**, on the Folio page. {i18n="folio.template.how.settings"}
4. Go to **Publish**, then **PDF & Print**. {i18n="folio.template.how.publish"}

When Bloom makes the PDF, it adds each book's first page number to the table of contents. {i18n="folio.template.pagenumbers"}

# Things to know {i18n="folio.template.know"}

- A folio can only use books that are in the same collection. {i18n="folio.template.know.collection"}
- A folio can only be published as a PDF. {i18n="folio.template.know.pdf"}
- If the list does not fit on one page, Bloom adds pages after it for the rest of the list, and takes them away again when they are no longer needed. {i18n="folio.template.know.morepages"}
